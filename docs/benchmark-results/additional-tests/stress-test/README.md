# Stress Test & Overload Resilience Benchmark (1200 RPS)

This folder contains the complete reproducible dataset, analysis scripts, and resulting visualizations for the **Stress Test / Graceful Degradation** scenario.

## 1. Dataset (Auto-Rerun)
The raw data originally contained 12 runs (3 runs per strategy). We have re-executed the `adaptive_full` strategy to capture a clean state and avoid JVM GC interference. 

The pipeline features a **Dataset Selector** that automatically prioritizes `adaptive_full_rerun_2026-07-22` over the noisy `adaptive_full` old folder, keeping the baselines intact.
*   **Total JTL Files**: 12 (3 for Adaptive, 3 for Least Connections, 3 for Random, 3 for Round Robin).
*   **Total Parsed Samples**: ~1.7 million HTTP Requests.

## 2. Methodology
The testing framework enforces a strict protocol:
1.  **Target Load**: 1200 Requests Per Second (RPS) generated by Apache JMeter.
2.  **Chaos Injection**: Random slowdowns injected into backend nodes to simulate network congestion or database locks.
3.  **Measurement Strategy**: 
    - Exclude warmup (`Setup`) and cooldown (`DISCARD`).
    - Parse only `MEASURE_` samples.
    - Export metrics: Throughput, Goodput (Successful RPS), Average Latency, P50, P95, P99, and Error Rate.

## 3. Aggregation & Standardization
Scripts inside the `scripts/` directory process the multi-gigabyte `.jtl` files into standard formats:
*   `data/jtl-summary.csv`: Aggregated run-level statistics.
*   `visualizations/data/01_stress_test_run_level.csv`: Formatted run-level data.
*   `visualizations/data/02_stress_test_aggregate.csv`: Mean of 3 runs per strategy.
*   `visualizations/data/04_stress_test_comparison.csv`: Head-to-head Baseline vs Adaptive.
*   `visualizations/data/05_stress_test_improvement.csv`: Relative Difference Calculation.

## 4. Charts & Interpretation
We generated 7 academic-grade charts (available in both `PNG` and `SVG` 300-DPI format):
*   **Figure 01 & 02 (Latency)**: Shows how Adaptive keeps the system responsive despite Chaos.
*   **Figure 03 & 04 (Error Rate & Throughput)**: Showcases how Adaptive achieves 99.9% Goodput, while baselines suffer ~40% failures.
*   **Figure 05 & 06 (Stability)**: Proves the deterministic nature of Adaptive compared to the high variance of Random/Round Robin.
*   **Figure 07 (Relative Difference)**: Highlights the precise percentage of improvement Adaptive offers against each specific baseline.

## 5. Reproducibility
To regenerate the full pipeline (from JTL to CSV to PNG/SVG):
```bash
# 1. Parse Raw JTL
python scripts/process_stress_test_results.py --raw-dir ../../../../benchmark-raw-results/additional-tests/stress-test --out-dir .

# 2. Generate Visualizations
python visualizations/scripts/generate_stress_test_visualizations.py
```
> **Note**: Do not modify the calculation formulas. The Pipeline is strictly locked to match the Official Benchmark methodology.
